# QLink2Desktop

> 把本机端口、Docker 容器、局域网 / 公网服务，一键放到飞牛 OS（fnOS）桌面。

## 🙏 项目来源

自从接触到了飞牛之后，很多东西都想放在飞牛上来，因为家里装了米家的设备，还有Home Assistant（为了联动美的的家电），还有米家的中枢网关和米家WIFI，在外面的时候有时候就想设置下路由器和中枢之类的，原来也用过很多的软件，但是都不是很好的能适用，在外面打不开，用过的有米大神的fndesk、XIAOBONET的扩展图标管理、古大羊的lucky等，米大神的fndesk用着很好，但是就是路由器这个链接一直没弄好，提示权限相关的限制，就是通不了，lucky也一直捅不过去，所以米家路由器一直没有转过去，这次这个程序的开发是最近有公众号在推fndocker-to-desktop，我就使用了一下，嘿，竟然给弄好了，惊喜，不过原始的界面还有一些逻辑我自己不是太喜欢，所以就有了这个程序，当然了，还是除了图标全AI,HAHA。。。谁让咱不会写代码呢。。。以上。。。

**本项目基于 fn-docker-to-desktop（把 Docker 放到桌面）二次重构而来。**

原项目提供了非常出色的核心思路——把任意服务注册成飞牛原生桌面应用、并借助飞牛 Connect 打通外网访问。没有这个起点，就没有本项目。

## ✨ 功能特性

| 能力              | 说明                                             |
| --------------- | ---------------------------------------------- |
| 🔍 自动发现         | 流式解析内核套接字表 + Docker API，自动列出本机端口与容器            |
| 🖥️ 一键上桌面       | 把端口 / 容器 / 代理 / 快捷方式注册为**飞牛原生应用**，出现在真实桌面上     |
| 🌐 反向代理         | 局域网、公网服务统一代理成本机端口，可测试连通性、可忽略自签证书               |
| 🔗 SSH 隧道       | 其它机器（另一台 NAS、软路由、树莓派）上的服务也能放到桌面                |
| 🏷️ Watchcow 兼容 | 直接识别 Docker Compose 里的 watchcow 标签，一键启用        |
| 🔤 文字图标         | 内嵌点阵字模 + 配色，无图可用时现场生成一枚                        |
| 🎨 明暗 × 六色系     | 白天 / 暗黑 / 跟随系统，六套色系一键切换，偏好存在浏览器本地，首帧不闪白        |
| 🔁 CGI 跳转       | 网址快捷方式经由飞牛 CGI 入口 302 到目标网站，桌面入口的主机限制不影响抵达     |
| ♻️ 一键重启         | 面板内直接重启本应用服务，服务回来时页面自动重连，不必跑回应用中心              |
| 🚪 零端口占用        | 通过**飞牛统一网关**（Unix Domain Socket）接入，不占任何 TCP 端口 |
| 🧹 桌面图标对账       | 启动时只补齐缺失项、只修复过期项，**健康项绝不重装**                   |
| 🛡️ 安全卸载        | 只清理 `qlink2d.` 命名空间下的包，绝不触碰用户的其它应用             |

## 📦 安装

1. 前往 [Releases](../../releases) 下载与设备架构匹配的安装包（文件名里带版本号）：
   | 文件                           | 适用设备                  |
   | ---------------------------- | --------------------- |
   | `qlink2desktop-<版本>-x86.fpk` | Intel / AMD 平台        |
   | `qlink2desktop-<版本>-arm.fpk` | ARM 平台（ARM 盒子、树莓派类设备） |
2. 飞牛 OS → **应用中心** → 右上角「手动安装」→ 选择 `.fpk` 文件。
3. 安装完成后桌面出现 **QLink2Desktop** 图标，点开即用。

> 💡 访问走的是飞牛统一网关（`/app/qlink2desktop`），**不占用任何端口**，也不会与其它应用冲突。  
> 如需局域网直连调试，可在启动环境里设置 `PORT` 环境变量。

> 🧭  
> 若页面停在启动态，12 秒后会把**版本号、文档 URL、加载失败的资源清单**直接写在页面上；  
> 这一条正是为了让「打不开」不再是一句无法排查的描述。  
> 如果应用中心提示"已是最新"或拒绝覆盖安装，请先卸载旧版再安装。

## 🚀 快速上手

打开面板后有四类入口：

1. **桌面应用** —— 已放到桌面的全部链接，可编辑、启停、重新同步、导出备份。
2. **发现** —— 四个标签页：本机端口 / 容器标签 / 局域网扫描 / 远程主机，勾选即可一键放桌面。
3. **图标库** —— 上传或生成图标，自动复用到桌面入口。
4. **设置** —— 界面主题（明暗 × 六色系）、门户名称、访问口令与启动行为。
5. **系统** —— 版本信息、对账结果、运行日志、日志下载，以及**重启本应用服务**。

第一次使用建议：进入「发现 → 本机端口」，勾选一个正在跑的服务，点启用，回桌面看图标。

> 🎨 **换个颜色**：设置页第一张卡片就是「界面主题」——白天 / 暗黑 / 跟随系统，  
> 外加晴空蓝、湖水青、新芽绿、紫罗兰、暖阳橙、玫瑰红六套色系。  
> 顶栏右侧也有一颗明暗切换按钮，不用每次都绕进设置页。  
> 这个偏好只存在**当前浏览器**里（localStorage），不会影响其它设备，  
> 也不会写进服务端配置；首帧之前就已生效，深色用户不会看到闪白。

## 🛠️ 从源码构建

依赖：Go 1.23+（或 Docker）、bash。打包会自动从官方地址下载 `fnpack`。

```bash
# 全部质量门禁（gofmt + go vet + go test + 前端 import 校验）
make check

# 网关等效端到端验证：用两个 HTTP 代理复刻飞牛统一网关的两种转发方式，
# 逐条验证「网关之后」页面能否正常打开（尾斜杠自愈 / 资源 / import 图 /
# 首屏单请求 / 鉴权边界 / 深链接回退）。真机白屏类问题只能这样复现。
make e2e

# 打包（默认 x86，用 VERSION 文件里的版本号）
make fpk
make fpk ARCH=arm

# 双平台一起出包（同一版本号，便于反复验证）
make fpk-all

# 正式发版：版本号 patch +1，再一次性构建双架构
make release

# 本地起服务调试
make run
```

## 🧭 架构一览

```
cmd/server          入口：server / cgi 双模式，飞牛统一网关接入
cmd/iconforge       从源图生成全套官方规格图标
internal/
  domain            领域模型：Link（定义）/ Status（运行态）严格分离
  store             JSON 持久化，原子写入 + 损坏文件隔离
  discovery         服务发现：procfs 套接字表 / Docker 标签 / 局域网扫描 / SSH
  proxy             反向代理：httputil.ReverseProxy + SSE 友好的传输层
  fnos              飞牛桌面注册：manifest / 包树 / appcenter-cli 编排 / 图标
  gateway           统一网关：Unix Socket 监听 + CGI 转发
  auth              口令派生 + 内存会话
  httpapi           REST API + SSE 实时事件
  logx              环形缓冲日志 + 轮转文件
  webui             原生 ES 模块前端，go:embed 内嵌，零构建步骤
  app               装配 + 编排器（对账 / 稳定端口分配 / 守护）
fnos-app/           本应用自身的 fpk 包骨架（manifest / cmd / config / wizard / ui）
scripts/            打包脚本（自动获取官方 fnpack）
docs/               架构说明
```

更多设计决策见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 🔐 关于 Root 权限

本应用声明以 `root` 运行，原因是它必须：

- 调用 `appcenter-cli` 安装 / 卸载**其它**桌面应用（这是产品的核心能力）；
- 读取宿主机视角的 `/proc` 套接字表与进程 fd，才能发现真实在跑的服务；
- 访问 Docker 的 Unix Socket 以枚举容器。
